How the pattern memory game works

The game plays a pattern on four coloured pads, each with its own tone. When it stops, press the same pads in the same order. If you are right, the pattern grows by one step and plays slightly faster. The first wrong press ends the game, and your score is the number of rounds you completed. You can also try the number memory test to challenge a different type of memory.

Tips to last longer

  • Say the pads in your head as numbers, like 3, 1, 4, 2, instead of trying to picture the colours.
  • Break the pattern into groups of three and remember the groups.
  • Use keys 1 to 4 on a computer for faster, steadier input.
  • Keep the sound on if you can. The tones can give you a second cue to remember.

Common questions

Do I need sound to play?

No. The game works with sound off. Each pad also has a number, and you can press keys 1 to 4.

Is there a maximum number of rounds?

No. The pattern keeps growing until you make a mistake.
