How many digits can most people remember?

Many people can hold about seven digits at once, and memory research often describes the usual range as five to nine. Your result changes with sleep, stress and distractions, so treat it as a fun snapshot rather than a measure of how good your memory is overall.

How the test works

The test starts with a single digit. After each correct answer the number gets one digit longer, and it stays on screen a little longer too. You can see a bar showing how much time is left. The test ends the first time you type a number wrong, and your score is the longest number you got right.

Tips to remember more digits

  • Split the number into small groups, like a phone number, instead of memorising each digit alone.
  • Repeat the groups quietly to yourself while the number is on screen.
  • Look at the whole number once, then focus, rather than reading it again and again.
  • Play when you are rested. Distractions cost more digits than you would expect.

Common questions

Is a higher score always better?

A higher score means you held a longer number this time. It is not a medical or intelligence test, so use it to compare yourself with your own earlier tries.

Can I get better with practice?

Yes, mostly by using tricks like grouping digits and repeating the groups to yourself.

Do you save my score?

No. Your best score for the current visit is kept on the page only and disappears when you leave or refresh.
