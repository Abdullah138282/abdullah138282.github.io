How the color difference test works

This online color difference test shows a grid of tiles that appear to have the same color, but one tile has a slightly different shade. Find and click the odd tile to score a point. The board becomes larger as the game continues, while the difference between the colors becomes more subtle.

You have 60 seconds to find as many odd shades as possible. A wrong click removes 4 seconds from the timer. Your final score is the number of different-color tiles you correctly identified before time runs out.

What does this color test measure?

The game is mainly a visual perception challenge. It asks you to notice small differences in color while working under a time limit. Your result can be affected by your attention, screen quality, lighting, display settings and viewing conditions.

It is not a clinical vision assessment and does not diagnose color blindness or any other eyesight condition.

How to find the odd color faster

  • Look at the entire grid first instead of checking every tile one at a time.
  • Keep your eyes relaxed and look for the tile that appears slightly lighter or darker.
  • Avoid screen glare and use a display with comfortable brightness and contrast.
  • Use a mouse or touch input that feels responsive so you can move quickly between rounds.
  • Practice the game to become more familiar with spotting subtle shade differences.

Why color difference scores vary

Your score is not determined by vision alone. Different screens can reproduce colors differently, and brightness, contrast, viewing angle and ambient lighting can change how easily two similar shades can be distinguished.

Because of these differences, your score is most useful as a personal game result. If you want to compare attempts, try to use the same device and similar lighting conditions each time.

Color difference test vs color blindness test

A color difference game is different from a color blindness screening test. This game is designed for entertainment and visual perception practice. A medical color vision assessment uses standardized testing methods and should be performed by an appropriate eye care professional when needed.

Common questions

Is this a color blindness test?

No. This is a visual perception game that asks you to find a slightly different shade. It is not a medical color blindness test and cannot diagnose color vision problems.

Why do my scores change on different devices?

Screens can display colors differently. Brightness, contrast, viewing angle, display quality and browser rendering can affect how easy small shade differences are to see.

How can I improve my color difference score?

Practice can help you become more familiar with the task. Reducing glare and using consistent display conditions can also make your results easier to compare.

Is my score saved?

Your best score is kept on the page for the current visit only. It is not saved as a permanent account score.
