Choose a brain game

Each Thinkora game focuses on a different task. Your result is specific to that game and can be affected by factors such as concentration, practice, fatigue, device performance and testing conditions.

Reaction speed

The reaction time test measures how quickly you respond after a visual signal appears. Results are shown in milliseconds, making the test useful for comparing your own reaction-time results across similar sessions.

What do brain games test?

Different brain games place different demands on performance. A reaction test emphasizes quick responses to a visual signal, while memory games require you to retain and reproduce information.

The color difference game focuses on finding a visual difference, while the mental math test involves solving arithmetic problems under time pressure. Because the tasks are different, their scores should be interpreted separately.

Brain games vs IQ tests

A brain game usually focuses on one particular task, such as reaction speed, memory, visual attention or arithmetic. An IQ test is broader and can include multiple types of reasoning tasks.

A score from a single brain game is therefore not the same thing as an IQ score. If you want to explore reasoning skills across several areas, try the free online IQ test .

After an IQ test, you can use the IQ percentile calculator to convert an IQ score into an estimated percentile.

How should you interpret your brain game score?

A single score can change from one attempt to another. Your performance may be affected by sleep, concentration, fatigue, stress, practice, distractions and the device you use.

For personal comparison, it can be more useful to repeat the same game under similar conditions rather than treating one result as a fixed measure of ability.

Thinkora does not use these game scores as a diagnosis or as a complete assessment of cognitive ability.
